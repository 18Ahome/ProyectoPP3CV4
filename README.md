# Proyecto: Paradigmas de Programación - ESCOM
Este repositorio contiene las prácticas, tareas y proyectos desarrollados para la materia de **Paradigmas de Programación** correspondiente al tercer semestre en la **Escuela Superior de Cómputo (ESCOM - IPN)**.

El proyecto está estructurado utilizando **TypeScript** como lenguaje principal y **Node.js** como entorno de ejecución.

## 🛠️ Tecnologías utilizadas

- **Node.js** (v18 o superior)
- **TypeScript**
- **tsx** (Para la ejecución directa y automatizada de archivos `.ts`)

## 🚀 Configuración del entorno

Si clonas este proyecto o lo ejecutas en los laboratorios de la escuela, sigue estos pasos para asegurarte de que funcione correctamente:

### 1. Requisitos previos
Asegúrate de que la computadora tenga instalado Node.js corriendo el siguiente comando en la terminal:
```bash
node --version
npm --version
```

### 2. Instalación de dependencias
Para instalar TypeScript y las herramientas de automatización de manera local dentro del proyecto, ejecuta:
```bash
npm install
```
*Nota: Si estás trabajando desde un entorno sin conexión a internet (como una USB en el laboratorio), asegúrate de incluir la carpeta `node_modules` antes de mover tu proyecto.*

## 💻 Cómo ejecutar el proyecto

Para evitar el proceso manual de compilar a JavaScript (`.js`) y luego ejecutar con Node, utilizamos `tsx` para compilar en memoria y ver los resultados inmediatamente.

Ejecuta tu archivo principal (por ejemplo, `pre.ts`) con un solo comando:
```bash
npx tsx pre.ts
```
